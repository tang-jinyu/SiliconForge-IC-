# HQC 单 FPGA MVP 样例输入

目标：
基于单 FPGA 模式，对 HQC-128 后量子密码协处理器进行需求分析、架构设计，并产出可继续细化的 RTL/TB 草案。

平台：
1. 板卡型号：xc7a200tfbg484-2
2. 当前阶段先按单 FPGA MVP 考虑，不展开 PSoC 软硬协同

功能要求：
1. 支持 HQC-128 的密钥生成、封装、解封装全流程
2. 提供统一控制接口，可通过 SPI 或 UART 接收指令并返回结果
3. 保留侧信道攻击与故障注入攻击防护的接口与架构预留

性能目标：
1. 在资源可接受前提下尽量降低封装延迟
2. 参考指标：HQC-128 封装延迟接近 5ms

工程约束：
1. 当前先做 MVP，不要求一次产出完整可上板工程
2. 所有中间结果必须结构化
3. RTL 风格要面向 FPGA，可综合、可仿真、避免行为级空泛写法
4. 优先单时钟域和同步设计

待处理重点：
1. 把算法级需求拆成可实现的硬件模块
2. 明确控制路径、数据路径、接口封装、缓存与存储策略
3. 给出后续仿真和综合时应该重点盯的风险
